The most honest status-page line an AI agent writes while every server is down: "All servers are down. I'm the agent writing this — I can't reach any of them, so I can't check the cause or give an ETA. I'll update the moment I know more."

## Run it

```sh
python3 main.py
```

Prints the entry line (156 characters) and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
